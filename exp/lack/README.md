# LACK 55×55 — experiment: phone assistant generated from an assembled 3D file

For testing only. `assistant.html` is one self-contained file made by the editor (`app/asm.html`, “生成装配助手”): the NORDEN assistant page and voice layer running on model data.

- 3D source: **IKEA 3D Assembly Dataset**, `LACK_30449908_55x55.glb`, © Inter IKEA Systems B.V. 2021,
  https://github.com/IKEA/IKEA3DAssemblyDataset — **CC BY-NC-SA 4.0**. The file here is an adaptation (geometry welded,
  parts recoloured, steps added) under the same licence. Not for commercial use.
- Step order, names and text were entered for a test; they are not the maker's wording.
